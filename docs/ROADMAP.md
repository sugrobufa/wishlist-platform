# ROADMAP — Wishlist Platform

Версия 0.3. Скоуп фаз выровнен по приоритетам дизайн-пакета (P0/P1/P2 из
`design/package/handoff/README.md`, турн 19b). Фаза закрыта, когда выполнен её
DoD: код + тесты + обновлённые `.env.example`, README и, при изменении
соглашений, CLAUDE.md.

## Phase 0 — Каркас

- Next.js 16 (App Router, TS strict), Tailwind v4, ESLint + Prettier, vitest,
  Playwright (e2e), GitHub Actions: lint + typecheck + test.
- **Дизайн-система из пакета**: генерация Tailwind-токенов из
  `design/package/handoff/tokens.json`; шрифты Archivo / Onest / Instrument
  Sans через next/font; изображения комнат (`design/package/refs/`) — в репо
  и на S3/CDN без изменений.
- `docker-compose.yml`: postgres 17 (+pgvector миграцией), redis, minio;
  `.env.example` из ARCHITECTURE §14.
- Prisma: схема ARCHITECTURE §4 целиком (включая каталог/распознавание за
  флагами), первая миграция; seed: 10 пресетов комнат из `rooms.json`,
  демо-комната.
- Auth.js: magic link (dev: ссылка в консоль) + Google (Apple/Telegram — при
  «укреплении», Phase 1–2).
- next-intl (ru), базовый layout на токенах.
- Worker BullMQ (`npm run worker`) + пример job; Sentry/PostHog через env.

**DoD:** `docker compose up -d && npm run dev` — вход/выход работает; токены и
шрифты соответствуют tokens.json; CI зелёный.

## Phase 1 — MVP: комната + тихое дарение (цикл целиком)

1. Онбординг (турны 11–12): почта → комната-пресет → набор зон (F/M/Все 10).
2. **Сцена** (турны 15a/17a): кадр комнаты, хотспоты из `rooms.json`, наезд
   камеры по формуле `motion.json`, кадры «открыто» кроссфейдом, сетка вещей
   со стаггером; призраки «хочу» (пунктир = состояние, тест); ambient-дрейф;
   reduced-motion; ворота hover. Телефон + десктоп из одной карты координат.
3. **Карточка добавления** (турн 8): вопрос «что это для тебя» (люблю/хочу);
   по ссылке — парсер v1 (normalize + fastPath, safeFetch/SSRF, кэш, фикстуры
   ≥6 магазинов), вручную — товар и услуга; поля WANT (цена + видимость,
   размер/цвет/желание); `image.ingest`; дедуп по canonicalUrl.
4. **Тихая бронь**: гость по `/r/:slug` без регистрации, бронь (тихая /
   подписанная / складчина-каркас), cancelToken, «занято» для гостей;
   хозяйке — только счётчик; регистрация гостя «по пути».
5. **P0-экраны (6)**: «что подарили» → зал славы (`receiveGift`, раскрытие
   имён один раз, предложение связи) · карточка вещи хозяйки · карточка вещи
   гостя · зона целиком списком · «мои брони» гостя · письмо-напоминание за
   3 дня (`mail` + `occasion.close`).
6. Профиль и настройки: набор зон, вкл/выкл зоны (исчезают с мебелью),
   спрятанные вещи, «укрепление» вторым способом перед первым шером; GDPR
   (экспорт/удаление).
7. Связи: список с историей («дарила 2 раза»), взаимно/слежу/смотрели; без
   поиска людей.
8. e2e happy path: регистрация → добавила «люблю» и «хочу» по ссылке →
   поделилась → гость тихо забронировал → хозяйка видит только счётчик →
   «что подарили» → «Дошло» → вещь в зале славы, связь появилась.

**DoD:** e2e из п.8 зелёный; инварианты §5 ARCHITECTURE покрыты тестами
(owner-DTO без брони; hidden не течёт; пунктир=WANT); Lighthouse mobile ≥90 на
комнате гостя; метрики PRD §11 считаемы SQL.

## Phase 2 — P1-пакет + наполнение

- **P1-экраны (8)**: складчина изнутри + оплата (провайдер — по решению о
  рынке) · день рождения (occasionDate, обратный отсчёт) · ошибки
  распознавания ссылки · спрятанные вещи · отмена брони · превью ссылки в
  мессенджере (OG) · пустая зона · подсказки.
- **Каталог v1** (`CATALOG_ENABLED`): 1–2 источника по рынку, `feed.ingest`,
  поиск при добавлении, `embeddings.build`, `/out/:token` + клики.
- **AI-скрин v1** (`RECOGNIZE_ENABLED`): фото/скрин → атрибуты → кандидаты →
  подтверждение (вход в карточке добавления уже есть).
- Playwright-fallback + 3–5 адаптеров приоритетных магазинов с фикстурами.
- PWA: manifest + `share_target` (Android) → карточка добавления.
- `price.refresh`: перепроверка цен WANT, бейджи изменения, письмо о
  недоступности.
- Сверка хотспотов трёх мужских комнат с кадрами (метка из дизайн-пакета).

**DoD:** ≥80% тестовых URL без ручной правки; добавление из каталога без
парсинга; распознавание зоны ≥60% на тестовом наборе; складчина проходит
целиком (с оплатой, если провайдер выбран); share из Android создаёт карточку.

## Phase 3 — P2-пакет + каналы

- **P2-экраны (8)**: спасибо дарителям · поиск по своей комнате · уведомления ·
  смена почты и передача комнаты · удаление комнаты с чужими бронями ·
  подсказка гостю · загрузка/оффлайн · партнёрские магазины (витрина).
- Стриминги для зоны музыки (Spotify / Яндекс.Музыка — по рынку).
- Браузерное расширение (MV3); Telegram-бот (если рынок РФ).
- Монетизация CPA: расширение источников, отчёты по кликам/конверсиям.
- Зал славы: three.js для вещей с 3D-моделью (только зал славы, остальное —
  фото); инерция от пальца, один направленный свет.

**DoD:** ≥1 новый канал наполнения в проде; учёт кликов и первая сверка CPA.
