# 67 — Новая фича: вся комната списком, без прогулки

**What to build:** Пункт 3 приёмки 07.08, вторая половина. Владелец:
«новое представление, где просто список всех вещей списком — для тех, кто не
готов и не хочет гулять по комнате».

Сегодня попасть к вещи можно единственным путём: сцена → зона → лист. Кто
пришёл по ссылке выбрать подарок за минуту, вынужден играть в комнату. Нужен
второй, плоский вход в то же содержимое.

**Status:** todo

## Чем это НЕ является

- Не «зона целиком списком» — тот экран доска рисует отдельно (турн 19b, P0
  №4: сортировка, фильтр «только свободные», массовое скрытие). Здесь **вся
  комната разом**, зона — лишь один из способов сгруппировать.
- Не замена сцене. Сцена остаётся главным входом; список — переключатель
  рядом с ней, а не вместо неё.
- Не новая модель данных. Ни одного нового запроса к БД сверх тех, что уже
  обслуживают зоны.

## Что сделать

Экран «вся комната списком» с двумя видами одного набора: **хозяйке** —
её вещи, **гостю** — то, что ему видно (фильтр на чтении уже есть).

- строка вещи: фото, название, состояние («люблю» / «хочу»), цена по правилам
  видимости, зона, к которой вещь относится;
- группировка по зонам с заголовками — порядок зон тот же, что в комнате;
- фильтр по состоянию (все / «хочу» / «люблю») — минимум; гостю дополнительно
  «только свободные», если это дёшево переиспользовать из гостевой сетки;
- переключатель «комната ↔ список» — одной кнопкой, состояние запоминать в
  адресе (`?view=list`), а не в куках: ссылкой на список надо уметь делиться;
- пустая комната — честное пустое состояние, а не голая страница.

Демо-призраки в списке **не показывать**: они существуют, чтобы объяснить
язык зоны в сцене; в плоском перечне это выглядело бы как чужие вещи. Пустая
комната → пустое состояние.

## Осторожно

- **Тихая бронь (инвариант №1)** — главный риск этого экрана. Хозяйке нельзя
  показать ни имени, ни того, ЧТО забрали; общий счётчик по комнате — можно.
  Гостю прогресс складчины виден, хозяйке — нет. Тест обязателен.
- **Цены (инвариант №8)**: «люблю» гостю — только если хозяйка разрешила;
  «хочу» — по `priceVisibility`; хозяйке её цены видны всегда.
- **Спрятанные вещи и выключенные зоны** гостю не отдаются (инвариант №5).
- Сериализация — только через `src/server/dto/*`, своей не заводить.
- Не трогать сцену и её геометрию.

## Дизайн

Экрана в макете нет. Отрисовка запрошена письмом `design/DESIGN-BRIEF-09.md`
(задание 3) вместе с «зоной списком». **Ждать её не нужно**: строку собрать
из существующих токенов и типографики карточки вещи (турн 8) и сетки зоны
(турн 15a). Приедет макет — сверяем и правим, это дешевле, чем простой.
