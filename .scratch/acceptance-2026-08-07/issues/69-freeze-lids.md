# 69 — Раскрытия: остановить съёмку, зафиксировать десять кадров

**What to build:** Пункт 6 приёмки 07.08. Владелец: «мы зависли на этой задаче
несколько дней». Решение принято — **съёмку раскрытий останавливаем**.

**Status:** todo

## На чём стоит решение

Счёт по `design/package/handoff/rooms.json`, не по письмам дизайна:

| | |
|---|---|
| зон в контракте | 130 |
| **с подключённым кадром раскрытия** | **10** |
| помечено `reshoot` — попытка была, не прошла | 112 |
| скрыто продуктом (предмета нет в интерьере) | 8 |

Подключены: `cream/travel`, `cream/anything`, `cream/flowers`, `cream/home`,
`gamer/travel`, `sport/anything`, `sport/sneakers`, `sport/travel`,
`study/events`, `study/sport`.

Из партии «чемоданы» (раунд 11, семь зон) подключено **ноль**. Три раунда
подряд метод не сходится по причинам, которые от нас не зависят: съёмка идёт
от архивных копий вместо наших баз, фон усредняется по всему кадру.

Главное: **фотографией «одна законченная комната» не достигается.** «Кремовая»
закрыта на 4 зоны из 13, а девять оставшихся — ровно тот тип, на котором метод
провалился трижды (группа мелких предметов: вешалки, флаконы, книги, винил).
Продолжать — значит ждать четвёртого раунда ради зон, которые по собственному
правилу дизайна снимать нельзя.

## Что сделать

Работа почти вся документная — код у нас уже готов к жизни без кадров
(тикет 64: 120 зон отвечают светом на приход камеры).

- **`design/BRIEF-lids.md`** — пометить в шапке замороженным: партии «чемоданы»
  и «коробки» отменены 07.08 решением владельца, файл остаётся историей метода.
- **`design/package/handoff/rooms.json`** — руками НЕ править. Флаги `reshoot`
  на 112 зонах оставить как есть: это честная летопись попыток, а не очередь.
  Убедиться, что ни один код не читает `reshoot` как «скоро будет кадр».
- **`src/config/design.ts`** — правило `accepted ⟺ openFrame` не трогать; в
  комментарии про раскрытия дописать, что десять — это окончательное число
  на обозримое время, а не промежуточное.
- **ADR** — записать решение по форме `docs/agents/domain.md`: раскрытие
  фотографией признано бонусом десяти зон, языком продукта назначен отклик
  светом. Пересмотр — только явным решением владельца, как с three.js.
- **Проверить, что обещание тикета 64 выполнено ровно**: у каждой из 122
  показанных зон есть либо кадр, либо свет, третьего нет. Тест на это уже
  написан — прогнать и сослаться на него.
- **`docs/ROADMAP.md` и `.scratch/STATE.md`** — снять раскрытия с очереди.

## Что остаётся открытым (не в этом тикете)

Владелец сказал: «при успехе отрисовать остальные комнаты». То есть если
дизайн вытянет предметные кадры (`DESIGN-BRIEF-09.md`, задание 2) —
возвращаемся к раскрытиям отдельным решением. Это условие записать в ADR как
«при каких обстоятельствах пересматриваем», чтобы через месяц не гадать.
