# 101 — «Списком» у хозяйки открывал 500

**What to build:** Владелец 08.08: «Кнопка Списком сейчас никуда не приводит»
плюс скриншот стенда: «This page couldn't load — A server error occurred».

**Status:** done · **P0** (экран продукта не открывался вовсе)

## Что это было

Не «ссылка никуда не ведёт» — **пятисотка на `/room/list`**. Воспроизведено
на проде через браузер и локально на поднятой базе, причина из лога сервера:

```
Error: Functions cannot be passed directly to Client Components
  <... groups={[...]} accent="#E7C9A9" roomHref=... zoneHref={function zoneHref}>
```

Серверная страница `/room/list` передавала в КЛИЕНТСКИЙ `RoomListView` проп
`zoneHref={(key) => `/room/zone/${key}`}` — функцию. Через границу RSC функции
не ходят, и React валит рендер целиком.

## Почему молчало так долго

`git log -S zoneHref` — проп появился в **тикете 67** (тот самый «вся комната
списком»). То есть экран не открывался с самого рождения.

Не заметили потому, что вход в него был тихой стрелочной ссылкой «Списком →»
среди мелкого текста. **Заметили ровно тогда, когда тикет 86 сделал её
кнопкой-пилюлей** — владелец увидел кнопку и нажал.

Ни `tsc`, ни `next build`, ни юниты этого не ловят: ошибка рантаймовая.
E2E на этот экран нет.

## Что сделано

- `zoneHref?: (key: string) => string` → **`zoneHrefBase?: string`**; адрес
  собирается внутри клиентского компонента: `${zoneHrefBase}${group.key}`.
  Строки границу пересекают свободно;
- страница передаёт `zoneHrefBase="/room/zone/"`;
- проверено локально на поднятой базе: `/room/list` отвечает **200**.

## Ловушка, чтобы не вернулось

`tests/rsc-boundary.test.ts` — ищет стрелки в пропах JSX у СЕРВЕРНЫХ модулей.
«Серверный» считается не по отсутствию `"use client"`, а по замыканию
импортов: всё, что тянут клиентские файлы, тоже уезжает в браузер, и функции
там законны (`onClick` у хотспота живёт именно так). Проверяются только
модули вне этого замыкания.

Второй тест держит сам проп: `zoneHrefBase` — строка, функцию сюда не вернуть.

## Урок

**Незаметный вход прячет сломанный экран.** Пока «Списком» была стрелочной
подписью, по ней не попадали ни владелец, ни мы. Стоит помнить при любой
правке навигации: сделали вход заметным — пройдите по нему сами.
