## Что приехало

`design/package/handoff/messages-ru.json` — словарь, переписанный дизайн-сессией,
и `design/package/handoff/tone.md` — памятка тона. **Читать памятку первым:**
она объясняет решения, а словарь их только применяет.

Сверка с текущим `messages/ru.json` (сделана при разборе):

| | Сколько | Что делать |
|---|---|---|
| Строк переписано | **113** | взять из пакета дословно |
| Ключей только в пакете | 1 (`_tone`) | служебная пометка, **в `ru.json` не переносить** |
| Ключей только в коде | **11** | пакет о них не знает — переписать самому по памятке |

Одиннадцать «сирот» — экраны входа по ссылке из тикета 19 (`SignIn.confirm*`,
`SignIn.expired*`, `SignIn.failed*` и соседи): они появились ПОСЛЕ того, как
дизайн собрал словарь. Их надо привести к тому же тону руками — по формуле
ошибок из памятки («что случилось + что делать», без слова «ошибка»).

## Главные правила памятки (полный текст — `tone.md`)

- **Везде «ты».** Сейчас на одном экране уживаются «Вы вошли как» и «коснись
  зоны» — два разных человека.
- **Ни одного восклицательного знака** во всём продукте.
- **Никаких родовых скобок**: «Подарил(а) {name}» → «Подарок от {name}».
  Требует фраза рода — переписать фразу, а не ставить скобку.
- Технические слова (`наезд`, `кадр «открыто»`, `хотспот`, `пресет`,
  `набор зон`) в интерфейсе не существуют.
- Пустое состояние говорит, **что сделать**, а не почему пусто. Исключение —
  зал славы: там объясняем устройство.
- Точка не ставится в конце короткой строки (кнопка, подпись, заголовок).

## Критерии

- [ ] `messages/ru.json`: 113 строк заменены значениями из пакета **дословно**;
      `_tone` не перенесён; структура ключей не изменилась
- [ ] 11 ключей-сирот переписаны в том же тоне (перечислить их в Comments
      со старым и новым текстом — это твоё авторство, оно должно быть видно)
- [ ] `messages/en.json`: набор ключей совпадает с `ru.json` (каркас en
      обязан быть полным), английские строки **не переводим заново** —
      памятка прямо говорит: рынок русский, черёд en придёт позже
- [ ] `messages/dev-login.{ru,en}.json` не трогать — служебный словарь вне
      продукта (тикет 29), у него свой тест на отсутствие «!»
- [ ] Тест на тон: во всём `ru.json` нет `!`, нет `(а)`/`(а/я)`-скобок,
      нет слова «ошибка», нет технических слов из списка памятки. Тест
      обязателен — иначе тон разъедется на первой же новой строке
- [ ] Тест на полноту: наборы ключей `ru.json` и `en.json` совпадают
- [ ] Живая проверка: главная, `/signin`, комната хозяйки, комната гостя,
      добавление вещи, пустые зоны — нигде не осталось «Вы»
- [ ] `npm run typecheck && npm run lint && npm test` — зелёные

добавлять; если для теста нужен список запрещённых слов, он живёт в тесте,
а не в словаре.
