# 238 — десять прямоугольников стоят на пустом месте

**Откуда:** обход тикета 233. Проверяя правило «прямоугольник берёт предмет
вместе с опорой», агент прошёл глазами по всем **28 зонам с
`placedBy: "composition"`** — и нашёл больше, чем чинил.

| | сколько |
|---|---|
| починено тикетом 233 | 2 |
| без предмета по определению (`objectAbsent`) | 4 |
| стоят верно | 8 |
| пограничных (предмет внутри, опора срезана) | 4 |
| **настоящих промахов** | **10** |

## Десять промахов

| адрес | что под прямоугольником | где предмет |
|---|---|---|
| `emerald/music` | полка НАД вертушкой | вертушка с мраморной консолью ниже, ≈519…571 × 168…216 |
| `gamer/music` | три четверти пустой стены | вертушка, колонки и полка-подставка ниже, за кромкой |
| `gamer/watches` | дверцы тумбы | шкатулка с часами выше |
| `gamer/books` | шкатулка с часами | винил и книги выше |
| `gamer/money` | стена рядом с копилкой | сама банка-копилка |
| `sport/money` | рама велосипеда рядом с копилкой | сама банка |
| `loft/money` | бумажный конверт рядом | сама банка |
| `sport/tech` | голая стена слева от круглого зеркала | ноутбук на столе |
| `loft/watches` | винил | шкатулка с часами выше |
| `loft/grooming` | пол под верстаком | несессер ниже-левее, флакон на столе выше |

Вырезки — `.scratch/acceptance-2026-08-14/233-rects/before/comp-*.jpg`.

**Почему их не чинили сразу:** тикет 233 их не называл, а на симптом приёмки
(«рамки предметов в воздухе») они не влияют — все, кроме `sport/tech`, стоят
правее окна правила пустых мест. Чинить их скопом внутри чужого тикета значило
бы переразметить десять зон без единой строчки задания.

## Что сделать

Переразметить тем же способом, что тикет 233: глазами по вырезкам, координаты в
кадре 630×351, `rectOld` и `remapNote` у каждой правки, `bloomAR` пересчитать
по формуле контракта.

**Три «копилки» стоит смотреть вместе:** `gamer/money`, `sport/money`,
`loft/money` промахнулись одинаково — рядом с банкой, но не на ней. Похоже на
один приём разметки, применённый трижды.

**Три пограничных букета** (`emerald/flowers`, `bold/flowers`,
`cottage/flowers` — букет без вазы) и `cottage/home` (низ корзины срезан) —
решить заодно: по правилу пакета 50 опора обязана входить, и ваза с кувшином
это опора.

## Границы

- Кадры комнат неприкосновенны.
- **У зоны с кадром раскрытия переразметка обязывает перемерить порог** и
  положить числа в `frameRemeasured` — правило, переписанное тикетом 233 с
  запрета на обязанность.
- Второй карты координат не заводить.

## Проверка

- вырезки до и после по каждому адресу;
- пересечения зон и реестр в `design-contract` пересчитать, новые пары
  объяснить поимённо;
- тройки пустых мест могут переехать — снимок в `empty-places` обновить с
  разбором, а не подгонкой;
- `npm run test`, `npm run lint`, `npm run typecheck`.
