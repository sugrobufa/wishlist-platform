# 240 — проза пакета под сторожем: запрещённые слова и числа

**Откуда:** пакет 52, README — предложение самого дизайна после третьего
промаха счётом за четыре пакета.

> 33 ключа, «семь и тринадцать», теперь «пятнадцать». **Это не внимательность,
> это отсутствующая проверка.** Правило себе: если число не посчитано по файлу,
> оно не пишется — ни в контракт, ни в README, ни в письмо.
>
> Предлагаю две проверки машиной у вас, обе дешёвые:
> 1. запрещённые слова из `tone.md` — по всей прозе пакета, не только по
>    строкам словаря;
> 2. числа рядом со словами «ключей», «строк», «зон», «комнат» — сверять со
>    счётом по файлу.
>
> Оба моих провала этого раунда — из прозы, которую не проверяет никто.

**Он прав по факту:** мы ловили эти числа руками четыре раза подряд (38 против
5, 6/14 против 7/13, 15 против 19, «стало 23» против 22). Каждый раз — счётом,
и каждый раз вручную.

## Что сделать

Два сторожа в `tests/`, оба читают пакет, а не продукт:

1. **Запрещённые слова в прозе.** Правила уже есть — `TONE_RULES` в
   `tests/messages-tone.test.ts` (они и его: `tone.md` пришла от дизайна).
   Прогнать их по ПРОЗЕ пакета: `README.md`, `CHANGES.md`, значения ключей с
   подчёркиванием, поля `note`/`why`/`rule` в контрактах.
   **Ожидание — не пустой список.** Проза дизайна пишется НАМ, и слова вроде
   «кадр» в ней законны: это язык контракта, а не интерфейса. Поэтому правило
   тут не «ни разу», а «названо поимённо»: список известных мест с причиной,
   как у расхождений словаря. Новое вхождение — тест назовёт файл и строку.
2. **Числа рядом со словами счёта.** Искать в прозе `\d+\s+(ключ|строк|зон|
   комнат|адрес)[а-я]*` и рядом — что считать. Полностью автоматически не
   выйдет: «27 ключей `Pool.*`» машина посчитает, а «пять экранов» — нет.
   Поэтому: считать то, что привязано к ИМЕНИ раздела или к маске ключей, и
   молчать про остальное. Один пойманный случай окупает сторожа.

## Границы

- Сторож читает ТОЛЬКО пакет: он не про наш код и не про наш словарь.
- Падать он должен с внятным «файл, строка, обещано N, посчитано M» — иначе
  его начнут пропускать глазами.
- Не переписывать `TONE_RULES` — переиспользовать. Если для этого их надо
  экспортировать из теста в модуль рядом, это правильная работа, а не обход.

## Проверка

- сторож ловит все четыре известных случая, если подсунуть ему старые пакеты
  (47, 50, 51, 52) — это и есть проверка на непустоту;
- `npm run test`, `npm run lint`, `npm run typecheck`.
