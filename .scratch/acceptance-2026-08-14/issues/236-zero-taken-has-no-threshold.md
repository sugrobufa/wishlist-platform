# 236 — при нуле забранных порога не бывает

**Откуда:** пакет 50, `handoff/round50/occasion-zero.json` (турн 56e) — ответ на
письмо 54, пункт 3. Мы спрашивали, какой строкой говорить ноль. Ответ сильнее
вопроса:

> Не строки не хватало, а правила. `Occasion.emptyTitle` = «В этот раз тихо» и
> `emptyHint` **уже были в словаре, вашей редакции** — я начал сочинять свои и
> почти завёл дубль.

## Правило

1. **При нуле забранных состояние DUE НЕ НАСТУПАЕТ.** Раскрывать нечего,
   необратимого шага нет, «Пора узнать, кто что подарил» было бы неправдой.
   Итог сразу открыт и пуст: `emptyTitle` + `emptyHint`.
2. **При нуле блока счётчика нет вовсе** — ни в ожидании (AHEAD), ни в комнате
   без даты (NO_DATE), ни здесь. Так же комната прячет свой счётчик при нуле
   (турн 11d).
3. **Строк на ноль не будет ни у `dueLead`, ни у `takenNumber`:** «0 вещей
   забрали» сообщает о том, чего не произошло.

## Что сделать

- в таблице состояний (`screen-state.ts`) появляется условие: `due` при нуле
  забранных не выбирается — экран идёт в `summary` (пустой итог);
- блок счётчика и лид со счётчиком не рисуются при нуле;
- пустой итог по числам 56e: кадр комнаты при .5 (как в AHEAD), заголовок
  `emptyTitle` 28/1.06 при .86, подсказка `emptyHint` 13/1.6 при .68, выход
  `Occasion.emptyBackToRoom` («В комнату — вещи на месте») целью 44, громкой
  кнопки нет;
- ключ `emptyBackToRoom` завести в словарь (сейчас он только у пакета);
- **`thanksGuest`: наша сборка `mailto` подтверждена.** Тема —
  `Occasion.thanksSubject` («Спасибо за подарок»), **тело пустое**: благодарить
  за человека заготовкой нельзя. Ключ темы уже в словаре;
- **строки «писать некуда» не будет** — дизайн снял её сам: «нарушает правило,
  которым я же обосновал скрытие». Мы её и не заводили; проверить, что нигде не
  осталось её места.

## Границы

- Инвариант №1 цел: счётчик прячется при нуле, а не показывает ноль.
- Инвариант №2 цел: при нуле раскрывать нечего, `revealedAt` ставится, как и
  раньше, первым заходом на открытый итог.
- Слова не сочинять: всё нужное уже в словаре.

## Проверка

- юнит: комната с нулём забранных не даёт `due` ни при каком дне рождения;
- юнит: при нуле нет ни лида со счётчиком, ни блока счётчика — ни в одном из
  четырёх состояний;
- юнит: пустой итог показывает `emptyTitle`/`emptyHint` и выход
  `emptyBackToRoom`, громкой кнопки нет;
- `npm run test`, `npm run lint`, `npm run typecheck`.
