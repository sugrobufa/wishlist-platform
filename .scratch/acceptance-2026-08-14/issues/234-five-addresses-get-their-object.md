# 234 — пять адресов получают свой предмет

**Откуда:** пакет 50, `handoff/round50/zones-eight.json` → `open`; решение
владельца 14.08: «размечай четыре адреса и бар, перерисовку пока не трогай».

Дизайн осмотрел все семь кадров глазами и нашёл предмет там, где мы считали,
что его нет. **Координат он не даёт нарочно** — «их измеряет разработка».

| адрес | что искать в кадре |
|---|---|
| `warm/music` | проигрыватель на мраморной консоли справа, под вазой с пионами; рядом стопка винила |
| `lux/music` | проигрыватель в мраморной нише справа, полкой ниже книг |
| `sport/watches` | витрина с часами на полке справа — стеклянная шкатулка, пять часов, рядом проигрыватель |
| `study/tech` | плёночная камера на кожаном сундуке слева внизу. **Проигрыватель справа НЕ брать — он уйдёт под `music`** |
| `study/bar` | барная тележка с графинами справа от стола — «вы правы, всё уже нарисовано» |

## Что сделать

1. **Измерить прямоугольники** по базовым кадрам, глазами по вырезкам
   (`scripts/rects-preview.mjs`). Система координат — кадр 630×351 (ADR-0006).
2. **Правило пакета 50 применять сразу:** прямоугольник берёт предмет ВМЕСТЕ С
   ТЕМ, ЧТО ЕГО ДЕРЖИТ — консоль, полку, нишу, тележку. Предмет без опоры
   читается артефактом (тикет 233, там же билеты).
3. **Снять четыре адреса** из `zonesHiddenByProduct` (`src/config/design.ts`):
   `warm/music`, `lux/music`, `sport/watches`, `study/tech`. Список не удалять —
   он остаётся рабочей дверью; уходят ровно эти строки.
4. **Завести полку `bar`** — «Бар и табак», ТОЛЬКО в мужских комнатах (решение
   владельца). В `study` она получает прямоугольник этим тикетом; в `gamer`,
   `sport`, `loft` бара в кадре нет — там она живёт по тикету 235.
5. Каждой правке — поле «было» (`rectOld`), как прежним переразметкам.

## Границы

- Кадры комнат неприкосновенны: перерисовку владелец отложил, здесь только
  координаты и слова.
- `rooms.json` править ТОЧЕЧНО, не переносом файла целиком: перенос стирает
  поля приёмки (проверено потерей раунда 20).
- Четыре адреса остаются скрытыми и этим тикетом не трогаются:
  `emerald/beauty`, `sport/gaming`, `study/gaming`, `loft/gaming` — дизайн
  сказал числом, что зацепиться не за что.
- Слова новой полки заводит ведущий вместе со словарём пакета 50.

## Проверка

- вырезки до и после по каждому адресу — в отчёт;
- после снятия из списка зона показывается, у неё есть прямоугольник, камера
  наезжает и метка горит на предмете (вырезкой);
- продукт показывает на четыре зоны больше: было 122 из 130;
- `npm run test`, `npm run lint`, `npm run typecheck`.
