# 03 — Зона: вкладки «Люблю»/«Хочу», сетка вещей, демо-призраки

**What to build:** Открытая зона показывает сетку вещей с вкладками «Люблю» и
«Хочу» (стаггер-появление по motion.json). Вещь «хочу» — пунктирный контур
акцентом комнаты + полоса 2px снизу; «люблю» — плотная плитка без контура.
У новичка зоны без своих вещей наполнены демо-призраками из пулов с пометкой
«пример — замени на своё».

**Blocked by:** 02.

**Status:** ready-for-agent

- [ ] Сетка вещей зоны из БД (items сервис), вкладки Люблю/Хочу, стаггер 60мс/плитка из motion.json
- [ ] Визуальный код состояний из items.json: пунктир = WANT (не «нет фото»!); вещь без фото — серая заливка; LOVE без фото — БЕЗ пунктира (unit-тест на классификатор плитки)
- [ ] Цена у WANT (по visibility), у LOVE — «люблю» / «Подарен в 2024 · мама»
- [ ] Демо-призраки: генерация из пулов zones.json для пустых зон, isDemo в DTO, не кликаются в бронь, исчезают при первой своей вещи в зоне
