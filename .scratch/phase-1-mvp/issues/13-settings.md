# 13 — Настройки: профиль, ник, смена пресета, зоны, дата праздника

**What to build:** Настройки хозяйки: имя и аватар; красивый ник для адреса
комнаты; смена пресета интерьера без потери вещей; набор зон и вкл/выкл
отдельных зон; скрытие вещей; дата праздника; выключение демо-призраков.

**Blocked by:** 04.

**Status:** done

- [x] Профиль: displayName, аватар (upload → MinIO, sharp-квадрат)
- [x] Ник: `[a-z0-9_]{3,30}`, уникален, занятие/смена; старый короткий код 301-редиректит на ник (тикет 07 маршрут)
- [x] Смена пресета: вещи остаются, зоны маппятся по ключам, несовпавшие → anything (тест «ни одна вещь не потерялась»); превью пресетов лентой как в онбординге
- [x] Набор зон (F/M/ALL) и вкл/выкл зоны; выключенная зона исчезает из сцены вместе с мебелью, её вещи скрыты от гостя, но не удалены
- [x] hidden-тумблер на вещи; активная бронь при скрытии снимается (связка с тикетом 09)

  считать живую бронь. Скрытие ВЕЩИ — другое: там бронь снимается.
  Закреплено тестами («брони НЕ рвутся», «включение обратно возвращает
  зону вместе с вещью и бронью»).
