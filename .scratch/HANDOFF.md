## Как проверять живьём

`docker compose up -d`; e2e поднимает свой сервер на :3100 и не спорит с
обычным dev. Локальную базу пересеять — `npm run db:seed`.

Телефонные проверки отдельно — **`npx playwright test --project=mobile
--no-deps`** (без `--no-deps` тянет за собой полный цикл: с тикета 176 у
мобильного проекта `dependencies: ["chromium"]`).

**Панель браузера не композитит кадры:** анимации не идут, `rAF` не вызывается.
Проверять КАРТУ, а не движение: снять переход, подставить крайние значения,
померить `getBoundingClientRect`. Приём, который работает: положить проверяемое
крупным элементом в левый верхний угол через `position: fixed` и снять скриншот.

Стенд — `https://155-212-143-124.sslip.io`. Посев идёт при каждом входе через
`/dev-login`; `?fresh=1` стирает комнату и уводит в онбординг — после него нужен
второй заход БЕЗ параметров, слаг при этом меняется. Отчёт посева —
`/dev-login?report=1`, там же поля `contractPhotosMissing` и `ownedWishes`.
