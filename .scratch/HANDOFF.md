## Что выучено сегодня — не повторять

1. **Пакет дизайна копировать В РЕПОЗИТОРИЙ В ТОТ ЖЕ ЧАС, как приехал.** Папка
   входящих живёт на машине владельца, и браузер кладёт следующий пакет НА
   МЕСТО предыдущего: раунд 36 мы так потеряли целиком (`zone-row.json`
   восстанавливали по своему же прочтению), 37 и 39 успели спасти. Теперь
   копируем первым делом, до единой строки кода.
2. **`git add <пути> && git commit` НЕДОСТАТОЧНО при параллельных агентах.**
   `commit` берёт ВЕСЬ индекс, а сосед мог зарядить туда своё между твоими
   `add` и `commit` — за день так трижды чужая работа уехала в чужой коммит.
   Правильно: `git commit -m "…" -- <пути>` (`-m` ПЕРЕД `--`, иначе git примет
   сообщение за путь). Для новых файлов сначала `git add`, потом тот же
   ограниченный `commit`.
3. **Next 16 блокирует КАТАЛОГ сборки, а не порт** (`<distDir>/dev/lock`):
   `npm run test:e2e` не стартовал при живом `npm run dev`. Починено тикетом
   155 — у e2e свой `distDir` из `webServer.env`. `next-env.d.ts` вышел
   из-под гита осознанно: он переписывается под текущий distDir при каждом
   старте, стабильного содержимого у него нет ни при каком выборе.
4. **Дефисы браузер рвёт сам** — проверка переноса длинного имени на слове с
   дефисами даёт ложное «не ломается». Брать слово без пробелов, дефисов и
   точек.
5. **Чужие данные не чиним и не сочиняем — фиксируем числом, чтобы изменение
   позвало.** Так оформлены коллизия знаков, ряд «угол» и расхождение
   `Occasion.hint`: список «знаем и ждём ответа» сверяется НА РАВЕНСТВО, то
   есть не растёт молча и не залёживается, когда дизайн починит.
6. **`PACKAGE_DRIFT` и `OWNER_REWRITE_*` — разные списки, и смешивать их
   нельзя.** В первом строка совпадает с доской слово в слово после
   переименований (это стережёт отдельная проверка), во втором поменялось
   содержание. Новое расхождение по содержанию — новый именованный список со
   своей причиной (образец — `PRODUCT_TRUTH_173`).

   число с нашим полем `rectOld`.** Совпало — вся его арифметика посчитана по
   старой карте. С раунда 40 это почти прошло: карта сошлась 130 из 130.
5. **Зелёному локальному прогону как гарантии CI** — см. п. 3.
6. Сквозному моку `unstable_cache` (Next Data Cache СЕРИАЛИЗУЕТ значение).
7. **`NOT { поле: false }` в Prisma по НУЛЛЯЕМОМУ полю** — писать
   перечислением: `OR: [{ поле: null }, { поле: true }]`.

## Как проверять живьём

`docker compose up -d`; e2e поднимает свой сервер на :3100 и **больше не
спорит с обычным dev** (тикет 155). Локальную базу пересеять — `npm run
db:seed`.

**Панель браузера не композитит кадры:** анимации не идут, `rAF` не
вызывается, `captureScreenshot` отваливается по таймауту. Проверять КАРТУ, а не
движение: снять переход, подставить крайние значения, померить
`getBoundingClientRect`. **Приём, который работает:** положить проверяемое
крупным элементом в левый верхний угол через `position: fixed` и снять
скриншот — так сегодня смотрели знаки на 22 px и подсказку в её оправе.
