## Чему НЕ верить

1. Тестам про геометрию зон — только глаза по вырезке.
2. **Числам как приёмке СВЕТА.** Ночь дважды переделывали по замерам: ждали

   Причина была в режиме наложения (`multiply` глушил сильнее, чем показывали
   цифры), а не в числе. **Свет принимается на телефоне.**
3. **Вырезкам из исходника с жёстким `\n` в тестах.** Рабочее дерево на
   Windows держит CRLF, CI — LF. Тест пустой комнаты резал файл по
   `indexOf("…\n")`: локально не находил ничего и проходил СЛУЧАЙНО, в CI
   находил и падал. Писать `\r?\n` либо не резать по позициям вовсе.
4. Письмам дизайна без своего счёта (см. выше, но ожидание сменилось).
5. Его `rooms.json` целиком — точечный перенос.
6. **Зелёному локальному прогону как гарантии CI** — см. п. 3.
7. `git add -A` при работающих агентах — коммитить явными путями.
8. Сквозному моку `unstable_cache` (Next Data Cache СЕРИАЛИЗУЕТ значение).
9. **`NOT { поле: false }` в Prisma по НУЛЛЯЕМОМУ полю** — писать
   перечислением: `OR: [{ поле: null }, { поле: true }]`.
10. Тестам, читающим папку входящих пакетов: в CI такого пути нет — нужные

## Как проверять живьём

Локально: `docker compose up -d`, e2e сам поднимает сервер на :3100.
**Панель браузера не композитит кадры**: анимации не идут вовсе,
`requestAnimationFrame` не вызывается, скриншоты не работают. Проверять
КАРТУ, а не движение: выключить переход, подставить крайние значения,
померить `getBoundingClientRect`.

## E2E — знать до правки

Прогон гоняется отдельным расписанием (`gh run list --workflow=e2e.yml`).
Шаг проверки инварианта №1 читает тела сетевых ответов хозяйки, и **читается
около половины**: Playwright не резолвит тело отменённого навигацией ответа
вообще. Это сеть, а не доказательство — доказывают юниты, они перечислены в
самом тесте. Не «чинить» это, подняв ожидания: однажды шаг уже висел 79
секунд и съедал бюджет всего прогона.
