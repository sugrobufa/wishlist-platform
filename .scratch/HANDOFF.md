   сравнить его число с нашим полем `rectOld`.** Совпало — вся его арифметика
   посчитана по старой карте (так было с приёмкой round34).
5. Его `rooms.json` целиком — точечный перенос.
6. **Зелёному локальному прогону как гарантии CI** — см. п. 3.
7. `git add -A` при работающих агентах — коммитить явными путями.
8. Сквозному моку `unstable_cache` (Next Data Cache СЕРИАЛИЗУЕТ значение).
9. **`NOT { поле: false }` в Prisma по НУЛЛЯЕМОМУ полю** — писать
   перечислением: `OR: [{ поле: null }, { поле: true }]`.

## Как проверять живьём

Локально: `docker compose up -d`, e2e сам поднимает сервер на :3100.
**Панель браузера не композитит кадры**: анимации не идут вовсе,
`requestAnimationFrame` не вызывается. Проверять КАРТУ, а не движение:
выключить переход, подставить крайние значения, померить
`getBoundingClientRect`. Скриншот панели мельчит страницу — но если положить
проверяемое крупным элементом в левый верхний угол (`position: fixed`), видно
хорошо; так сегодня смотрели знаки на 22 px.

Стенд — `https://155-212-143-124.sslip.io`. **Посев идёт при каждом входе
через `/dev-login`.** `?fresh=1` стирает комнату и уводит в онбординг — после
него нужен второй заход БЕЗ параметров, слаг при этом меняется. Локальную базу
можно пересеять `npm run db:seed`.
