## Правила конвейера

Тикет = субагент с чистым контекстом; без git/зависимостей/dev-серверов;
коммит по путям после приёмки ведущим; параллельно — только непересекающиеся
территории (`messages/**` всегда общий — перечитывать с диска); Status: done
+ Comments. Живые проверки — ведущий. Партии дизайна: быстрая таблица сразу,
глаза обязательны, его файлы контракта — только точечно.
