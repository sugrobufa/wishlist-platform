## Главное решение вечера: правило съёмки

двигается **один цельный предмет с крышкой**: чемодан 3/3, коробка 2/2,
витрина, стойка, поднос. Проваливается группа мелочей (вешалки, флаконы,
карточки, книги, винил) — модель их перерисовывает. Размер зоны ни при чём.

`design/BRIEF-lids.md`. Остальным зонам — свет в коде (тикет 64, сделано).

**Движения денег в проекте нет** — подтверждено владельцем. Экран «оплата

## Правила конвейера

Тикет = субагент с чистым контекстом; без git/зависимостей/dev-серверов;
коммит **по путям** после приёмки ведущим; параллельно — только
непересекающиеся территории (`messages/**` общий: точечный Edit с
перечитыванием). Живые проверки — ведущий. Партии дизайна: быстрая таблица
сразу, глаза обязательны, его файлы контракта — только точечно.
**Пушить каждый коммит сразу** — владелец следит по стенду.
