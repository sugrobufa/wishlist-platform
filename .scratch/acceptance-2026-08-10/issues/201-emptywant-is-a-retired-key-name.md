# 201 — `ZoneGrid.emptyWant`: снятое имя вернулось и живёт в сборке

**Откуда:** вопрос дизайна в пакете 46 (`empty-zone.json → keyNameQuestion`).
Он спросил, какое имя живое у нас, и оказался прав.

## Проверка

| где | имя | значение |
|---|---|---|
| словарь ПАКЕТА, `handoff/messages-ru.json:77` | **`ZoneGrid.empty`** | «Добавь первое желание» |
| наш `messages/ru.json` | **`ZoneGrid.emptyWant`** | «Добавь первое желание» |

**Значение совпадает дословно. Расходится только имя, и имя наше.**

У дизайна `emptyWant` числится в списке ключей, СНЯТЫХ письмом 25 вместе с
состояниями вещи. То есть имя пережило отмену модели: состояний нет с
09.08.2026 (тикет 124), а слово «want» осталось в ключе.

Зовётся из двух мест:

- `src/components/zone/ZoneGrid.tsx:169` — пустая зона у гостя;
- `src/app/room/zone/[zone]/owner-zone-grid.tsx:393` — пустой список зоны.

## Решение

1. Переименовать `ZoneGrid.emptyWant` → `ZoneGrid.empty` в `messages/ru.json`
   и `messages/en.json`, значения не трогая;
2. поправить два места вызова;
3. **убрать запись из списка сирот** `tests/messages-tone.test.ts`: после
   переименования ключ становится тем, что пакет знает, и уходит в обычную
   сверку «перенесено дословно». Сторож сверяет списки НА РАВЕНСТВО —
   забытая запись покраснеет.

## Границы

- Ни одной строки продукта на экране не меняется: это переименование ключа.
- Соседний `ZoneList.emptyHidden` не трогать — у него своё имя и свой смысл.

## Проверка

- `grep` по `src/` на `emptyWant` — пусто;
- `tests/messages-tone.test.ts` зелёный, и ключ ушёл из сирот;
- `npm run test`, `npm run lint`, `npm run typecheck`.

**Зависимость:** `messages/**` — общая территория. Делать, когда её никто не
держит.
