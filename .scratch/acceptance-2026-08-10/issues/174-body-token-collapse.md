# 174 — двенадцать захардкоженных `rgba(255,249,242,.72)` схлопнуть в токен

**Откуда:** хвост тикета 164 (лестница токенов раунда 41). Там ступени `.68` и
`.72` слились в одну — `text.body` — и в `src/styles/tokens.css` появилось
`--color-text-body: rgba(255,249,242,.72)`. Двенадцать мест в восьми файлах
продолжают писать то же значение числом. Тикет 164 замену **отложил осознанно**:
два из двенадцати лежали в сцене, а сцена была занята соседним агентом, и
схлопнуть десять из двенадцати хуже, чем не трогать — получился бы файл, где
половина мест на токене, а половина числом.

**Сцена свободна.** Делаем весь заход целиком.

## Что менять

Ровно те двенадцать (проверено `grep` на `255, 249, 242` и `255,249,242`):

| файл | сколько |
|---|---|
| `src/components/item/owner-card.module.css` | 4 |
| `src/components/zone-row/zone-row.module.css` | 2 |
| `src/app/connections/feed.module.css` | 1 |
| `src/components/room-list/room-list.module.css` | 1 |
| `src/components/zone/shop-link.module.css` | 1 |
| `src/components/zone/zone-grid.module.css` | 1 |
| `src/components/scene/scene.module.css` | 1 |
| `src/components/scene/zone-list.module.css` | 1 |

Каждое `color: rgba(255, 249, 242, 0.72)` → `color: var(--color-text-body)`.

## Границы

1. **Только точное значение `.72` в свойстве `color`.** Другие альфы того же
   белого (`.45`, `.55`, `.6` и прочие) — НЕ трогать: у них своя ступень, и
   слияние их не касалось. Если по дороге попадётся `.72` не в `color`
   (граница, тень, фон) — не менять и назвать в отчёте.
2. **`src/styles/tokens.css` не трогать** — там объявление токена, оно и есть
   правило.
3. Комментарий-справка в шапке `zone-row.module.css:19` (`rgba(255,249,242,.72)
   · знак ⋯ 19 …`) — это ПРОЗА, описание контракта. Оставить как есть.
4. Ни одного числа не подгонять «заодно»: пиксели, радиусы, длительности — мимо.

## Проверка

- вырезка не нужна: значение токена побайтно равно тому, что стояло числом,
  вид не меняется. Доказательство — равенство, а не глаза;
- `npx vitest run tests/design-contract.test.ts tests/zone-row-52.test.ts
  tests/zone-row-mobile.test.ts tests/item-card-owner.test.ts
  tests/tile-appearance.test.ts tests/immersive-layout.test.ts`;
- `npm run lint`, `npm run typecheck`;
- финальным `grep` показать, что в `src/` не осталось ни одного `255,249,242`
  вне `tokens.css` и вне комментария-справки.

## Тест

В `tests/design-contract.test.ts` добавить проверку-сторож: **`.72` белого не
пишется числом нигде в `src/**/*.css`, кроме объявления токена**. Иначе
следующая правка вернёт число молча, и лестница разъедется второй раз.
Сторож ищет по обоим написаниям (с пробелами и без) и по обеим формам альфы
(`0.72` и `.72`); комментарии из проверки исключить — справка законна.
