# 191 — выпилить автонаполнение комнаты

**Откуда:** приёмка владельца 11.08.2026, пункт 5 из шести:

> «Нужно выпилить функционал автоматического наполнения комнаты. Для любой
> женщины это оскорбление, ведь она сама должна наполнить пространство»

Это решение владельца о продукте, а не задача на улучшение. Довод его же:
комната — своё пространство, и наполнить его чужой рукой значит отнять
единственное, ради чего человек сюда пришёл.

## Что именно уходит

Кнопка «Или начни с готового · +60» на пустой комнате (скриншот владельца) и
всё, что за ней стоит:

| файл | что |
|---|---|
| `src/app/room/starter-pack.tsx` | компонент целиком (вместе с вопросом — тикет 189) |
| `src/app/room/starter-pack-actions.ts` | `applyStarterPackAction`, `saveWantsAction`, `starterPackWantsAction` |
| `src/server/services/starter-pack.ts` | сервис |
| `src/server/services/pack-seeds.ts` | зёрна набора |
| `messages/{ru,en}.json` | секция `StarterPack.*`, `Onboarding.wants*` |
| `src/app/room/page.tsx` | место вызова и подсчёт `size` |
| `src/app/globals.css` | `.imm-starter*` |
| тесты | всё, что держит набор |

**Демо-призраки (`look.ghost`, `demoBadge`) — это другое** и остаётся: они
показывают, как выглядит полка с вещами, и вещами не становятся.

**Посев стенда — тоже другое** (`npm run db:seed`, тикет 175): это наш
инструмент разработки, а не предложение человеку.

## Порядок

1. убрать вызов из пустой комнаты — экран перестаёт предлагать набор;
2. убрать компонент и действия;
3. убрать сервис и зёрна;
4. убрать строки и стили;
5. убрать тесты набора; тесты, которые ПРОВЕРЯЮТ ОТСУТСТВИЕ, — завести.

Шаг 5 не формальность: **функция, выпиленная без сторожа, возвращается**.
Нужен тест «на пустой комнате нет ни одного действия, кладущего вещи пачкой»,
и он обязан падать при возврате любого из путей.

## Границы

- **База не трогается.** Вещи, положенные набором у живых комнат, остаются
  вещами их хозяек: они уже свои. Никаких удалений по признаку происхождения.
- Онбординг не трогать (кроме ухода строк `wants*`).
- Форму добавления не трогать — тикет 190 про неё.

## Что сказать дизайну (письмо 47)

Набор — его решение: доска Б23 · турн 12c, `task15.json →
emptyStates.emptyRoom.starterPack`, вердикт «по согласию». Мы убираем не
исполнение, а саму идею, и по причине, которой у дизайна в разборе не было:
**владелец считает предложение наполнить комнату за человека обидным**.
Сказать прямо и попросить не присылать его снова в следующих раундах.

## Проверка

- пустая комната: ни одного пути, кладущего больше одной вещи за нажатие —
  тест на отсутствие;
- `grep` по `src/` на `starterPack|StarterPack|applyStarterPack` — пусто;
- словари: осиротевших ключей `StarterPack.*` не осталось, список сирот в
  `tests/messages-tone.test.ts` подчищен (сторож сверяет НА РАВЕНСТВО и
  покраснеет от забытой записи);
- пустая комната по-прежнему предлагает добавить первую вещь (тикет 190);
- `npm run test`, `npm run lint`, `npm run typecheck`.
