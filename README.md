# Wishlist Platform — пакет передачи в Claude Code

Рабочее название: **wishlist-platform** (имя/домен — открытый вопрос, PRD §12;
в шорт-листе Dome / dome.space, Wish Space / wish.space, Doma, Nora).

**Комната** человека: личная страница — фотореальный интерьер, где мебель —
зоны его мира (полки → книги, гардероб → одежда, проигрыватель → музыка).
У вещи два состояния: **«люблю»** (уже моё, показываю) и **«хочу»** (жду в
подарок, бронируется). Гости **тихо** бронируют подарки — хозяйка видит только
счётчик; после праздника «что подарили» отправляет вещи в зал славы,
раскрывает дарителей и заводит связи. На телефоне комната не уменьшается —
она приближается.

## Состав пакета

| Путь | Что внутри |
|---|---|
| `CLAUDE.md` | Инструкции для Claude Code: стек, конвенции, инварианты |
| `docs/PRD.md` | Продукт: модель «люблю/хочу», цикл дарения, комнаты, скоуп P0–P2 |
| `docs/ARCHITECTURE.md` | Архитектура: сцена, модель данных, тихая бронь, каталог/AI, масштаб |
| `docs/ROADMAP.md` | Фазы с definition of done |
| `design/package/` | **Дизайн-пакет — источник правды UI**: интерактивный макет `Main Screen.dc.html`, handoff-контракты (items / rooms / zones / tokens / motion), 41 изображение комнат |
| `design/DESIGN-BRIEF.md`, `design/inspiration/` | Исходная постановка и референсы (история) |

## Запуск локально (Phase 0 готова)

```bash
docker compose up -d      # postgres (+pgvector), redis, minio
npm install
npx prisma migrate dev    # миграции + сид (демо-комната /r/demo)
npm run dev               # http://localhost:3000
npm run worker            # отдельный терминал: BullMQ-очереди
```

Вход в dev-режиме: почта + ссылка; ссылка печатается в консоль dev-сервера
(EMAIL_SERVER пустой). Проверки: `npm run lint && npm run typecheck && npm test`.

## Как использовать

1. Создайте пустой репозиторий и скопируйте в его корень содержимое этой папки.
2. Откройте папку в Claude Code — он автоматически прочитает `CLAUDE.md`.
3. Стартовый промпт:

```
Прочитай CLAUDE.md, docs/PRD.md, docs/ARCHITECTURE.md, docs/ROADMAP.md и
design/package/handoff/README.md (+ items.json). Затем выполни Phase 0 из
ROADMAP.md: каркас Next.js + TypeScript + Prisma + Docker Compose
(Postgres/Redis/MinIO), токены из tokens.json, авторизация magic link, CI.
После каждого шага показывай, что сделано, и сверяйся с DoD фазы.
```

4. Дальше по фазам: Phase 1 (MVP: комната + тихое дарение) → 2 → 3.

Посмотреть дизайн: открыть `design/package/Main Screen.dc.html` в браузере
(двойной клик). Рабочие экраны: 15a (телефон), 17a (десктоп).

## Ключевые решения (зафиксированы дизайн-пакетом)

- Одна вещь, два состояния «люблю/хочу»; переход один — «Дошло» после
  праздника (зал славы, раскрытие дарителя, связь). `handoff/items.json`.
- Тихая бронь: хозяйке — счётчик, не имена и не вещи. Складчина ≥5 — исключение.
- 10 комнат-пресетов, 84 зоны одной картой координат (430×352, десктоп
  ×1.7778), наезд камеры считается формулой. Изображения комнат
  неприкосновенны — хотспоты привязаны к кадрам.
- Друзья не добавляются: связь из подарка или ссылки.
- Вход без пароля (почта + ссылка); второй способ — перед первым шером.
- Стек: Next.js 16 + React 19 + TS, PostgreSQL 17 (+pgvector) / Prisma,
  Redis/BullMQ, Tailwind v4 (токены из `tokens.json`), путь масштабирования
  до миллионов — ARCHITECTURE §9. Каталог фидов и AI-распознавание заложены
  в схему, включаются флагами в Phase 2–3.

Открытые вопросы — `docs/PRD.md §12` (рынок, имя, монетизация, платёжка
складчины, индексация, порог складчины, стриминги).
