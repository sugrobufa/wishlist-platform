# Оригиналы 5504×3072 — как забрать

## Что есть сейчас

| | Разрешение | Формат | Где |
|---|---|---|---|
| Что отдано | **2400×1340** | JPEG q0.88 | `refs-2x/` |
| Оригинал у поставщика | **5504×3072** | PNG, ~20 МБ | ссылки в `masters.json` |

Claude Code прав: **2400 px — это не 4К.** Кадры уменьшил я, при сохранении, чтобы архив
не разросся до трёх гигабайт. Оригиналы никуда не делись.

## Сколько на самом деле нужно

Считаем от сцены, а не от круглого числа:

| Экран | Ширина сцены | DPR | Наезд | Нужно пикселей |
|---|---|---|---|---|
| Телефон | 430 | 3 | 1.72 | 2 219 |
| Десктоп | 1120 | 2 | 1.45 | **3 248** |

**2400 px хватает в покое и не хватает при наезде на десктопе** — там не хватает трети.
Порог, ниже которого нельзя, — 3250 px. Оригинал 5504 закрывает его с запасом.

Рекомендация: сохранять **4096 px, JPEG q0.90** (~2 МБ на кадр, ~290 МБ на все 144).
Хранить 5504 в PNG смысла нет: 3 ГБ ради пикселей, которых не увидит ни один экран.

## Почему я не могу скачать их сам

Мой скрипт живёт 30 секунд. Один кадр — 20 МБ на скачивание плюс декодирование
5504×3072 плюс перекодирование. За один заход проходит один-два файла, на 144 нужно
около сотни заходов. У Claude Code таких ограничений нет — там это одна команда на минуту.

## Что скачивать: сопоставление по содержимому

В `masters.json` 144 ссылки, но **без имён**: имя файла у поставщика — это UUID задания,
а не `o-warm-jewelry`. Сопоставлять надо по картинке. Файлы в `refs-2x/` — те же кадры,
поэтому уменьшенные до 24×14 они совпадают почти точно.

```js
// 1. отпечаток каждого локального файла
const fp = new Map();
for (const f of glob('refs-2x/*/*.jpg')) fp.set(f, thumb(f, 24, 14));

// 2. для каждого оригинала — ближайший локальный
for (const url of masters.urls) {
  const png = await download(url);
  const t = thumb(png, 24, 14);
  const [name, dist] = nearest(t, fp);        // L1 по яркости
  if (dist > 8) { report(url, 'нет пары');  continue; }
  save(`refs-4k/${name}`, resize(png, 4096), 'jpeg', 0.90);
  fp.delete(name);                             // пара занята
}
```

`thumb` — уменьшить до 24×14 и взять яркость `0.299R + 0.587G + 0.114B`.
`nearest` — минимум суммы модулей разности по 336 значениям.

**Порог 8.** Свой кадр даёт расхождение около нуля, чужой — за сорок. Промежутка почти
нет, поэтому порог можно ставить грубо. Совпадений должно найтись 140; лишние
четыре ссылки — отбракованные дубли, их не будет пары, и это правильно.

После прогона: `refs-4k/` повторяет структуру `refs-2x/` файл в файл, и в `rooms.json`
достаточно заменить префикс пути.

## Проверка

```
count(refs-4k/**/*.jpg) == 140
min(width) >= 4096
```

Если какой-то кадр не нашёл пару — скачайте его вручную и посмотрите глазами:
`refs-2x/` показывает, чего не хватает.
