## Правило, которое меняет данные, а не вид

**При скрытой цене продукт не печатает ни одного числа денег** — ни своего, ни
разобранного из магазина, ни «от». Из этого следует, что в гостевом ответе при
скрытой цене не должно быть денежных полей ни в разметке, ни в данных.
Записано в словарь как `_hiddenPriceRule`.
