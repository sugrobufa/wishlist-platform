# Нить бирки — вставка

SVG лежит рядом: `tag-thread.svg`, размер ×1 (под бирку 124 × 44).

## Куда

Внутрь обёртки бирки (`position: relative; width: 124px; height: 44px`),
**первым ребёнком — до** элемента с `clip-path`:

```html
<div style="position:relative;width:124px;height:44px">
  <!-- tag-thread.svg сюда -->
  <div style="…clip-path:polygon(0% 50%, 15% 0%, 100% 0%, 100% 100%, 15% 100%);
              transform:rotate(-3deg);transform-origin:16.5px 22px">…</div>
</div>
```

## Два условия

1. **Снаружи элемента с `clip-path`.** Внутри скос обрежет нить по диагонали.
2. **`overflow: visible`** на самом SVG (уже стоит в файле): узелок выходит за
   верх холста.

## Чего нить не делает

**Не наклоняется вместе с бумагой.** Поворот −3° живёт только на элементе
бирки — оттого и `transform-origin` стоит в отверстии (16.5 / 22). Если
повернуть нить, вернётся ровно то, на что жаловался владелец.

## Почему дуг три

- одна дуга кончается на бумаге и читается как царапина;
- две сходятся к узелку — уже петля, но непонятно, чем держится;
- третья, короткая, проходит **через проём** и отвечает на это.

Два оттенка не украшение: `#C9A87A` — ближний конец, `#B9946A` — дальний.
Без разницы в тоне дуги слипаются в ленту.
