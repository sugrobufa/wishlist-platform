# Как снимать кадры «открыто» — метод найден

Способ, которым снят комплект «Тихой роскоши». Он решает противоречие, из-за которого
раунд 2 не смог отдать ни одного нового кадра.

## Противоречие

Бриф требует: кадр «открыто» — это **тот же кадр**, где изменился один предмет, геометрия
совпадает до пикселя. Текстовая генерация этого не может: каждый прогон рисует новую сцену.
Поэтому прежние 30 кадров и вышли крупными планами — единственный способ обойти
несовпадение — и именно поэтому они нарушают пункт 8.3 брифа.

## Решение

Nano Banana Pro принимает **входное изображение** и правит его локально. Схема:

1. Публичный URL существующего кадра комнаты → импорт в Higgsfield → `media_id`.
2. Генерация с этим `media_id` в роли `image`, разрешение 4k, промпт по шаблону:

```
Keep this interior photograph exactly as it is — same camera, same framing, same lighting,
same colour, every object in the same place — and change ONE thing: <предмет> now stands
fully OPEN, <что открылось>. Everything else in the room is untouched and pixel-identical.
Photorealistic, 35mm, natural film grain.
```

3. На выходе 5504×3072 — та же композиция, изменён один предмет, детализация выше исходной.

**Исходник для всех правок — один и тот же базовый кадр комнаты.** Не правка правки:
иначе расхождения накапливаются. Каждый кадр «открыто» — прямой потомок базового.

## Проверка совпадения

Считается численно: обе картинки приводятся к 240×134, берётся средняя абсолютная разница
яркости, целиком и по шести вертикальным полосам.

| Что | Целиком | По полосам L→R |
|---|---|---|
| Детализирующая правка базового | 0.041 | 0.043 0.053 0.042 0.035 0.045 0.031 |
| Шкатулка открыта | 0.046 | 0.045 0.055 **0.062** 0.040 0.043 0.031 |

Ровный фон 0.03–0.05 — это добавленная детализация, не сдвиг. Признак правильной правки:
**одна полоса выше остальных**, там где изменение (0.062 в центре — туалетный столик).
Сдвиг композиции дал бы 0.15+ и не в одной полосе.

Порог для приёмки кадра: фон ≤ 0.06, пик в полосе изменения ≤ 0.10. Выше — кадр
перерисовался, брать нельзя.

## Что это даёт по обеим просьбам сразу

**Высокое разрешение без пересъёмки координат.** Правка не меняет геометрию, значит
прямоугольники комнаты остаются действительными. Ровно то, чего требует пункт 8.5.

**Полный кадр вместо крупного плана.** Кроссфейд идёт между двумя кадрами одной сцены —
раскрытие видно на месте, а камера остаётся там, куда её привёл наезд.

**Кроп больше не мешает.** Базовый кадр не перекомпоновывается, значит вопрос «зоны в левых
двух третях» снимается: композиция уже проверена продуктом.

## Стоимость комплекта

13 генераций на комнату (1 базовая + 12 зон) плюс деньги. Батчами по 6, около трёх минут
на комнату. Десять комнат — 130 генераций.
