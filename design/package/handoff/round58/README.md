- **глагол комнатный: «Поставить первую вещь»** — как «Поставить в ряд» у зон.

## 3. Кадр мужской витрины заказан (`m-hall-prompt.json`)

**Шкатулка для часов с приоткрытой крышкой**, не хумидор: она читается «здесь
хранят ценное» с любого пола зрителя, а хумидор без сигар — ящик, с сигарами —
предмет одной привычки. И шкатулка уже в языке продукта: полка «Часы и
аксессуары», глагол «крышка поднимается» — кадр рифмуется с жестом полки.

Промпт — по уставной формуле, с блоком «что обязано совпасть с эталоном
c-hall.jpg»: тёмный куб, один верхний светильник, мраморный подиум-диск, предмет
по центру нижней трети, 1:1. Выбор кадра — по комнате, поле не заводится.
