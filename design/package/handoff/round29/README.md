## Задание 31 — ответ на настоящий вопрос, не на прежний

**1 · Степеней нет ни у одной (56 из 57).** Законный вид, не вырождение:
слотов под огоньки не существует — сетка ничего не обещает, отсутствие не
читается дырой. Порядок откатывается к новизне. Сигналы зоны целы: цена,
приглушение «уже дарят», бирка у гостя.

**2 · Степень у части.** Не поломка: огоньки — свойство мета-строки при
цене (как заметка), не ряд шкалы. Ваша сортировка подтверждена: 4 → 1,
дальше «не скажу» по новизне.

**3 · Заголовков степеней нет никогда; воздух постоянный.** Количество
лечат ярусы ширины: 1–2 вещи — во всю ширину; 3–6 — первая широкая +
двухколонник; 7+ — плотный двухколонник. При 40 работу делает порядок.
Единственные законные заголовки — имена зон в /room/list (там же: пустые
зоны секциями не рисуются).

**4 · Причину чиним подъёмом, не принуждением.** Обязательным поле не
делать — «не скажу» законное пустое (инвариант). Шкала переезжает вторым
вопросом формы (после названия): 4 огонька на целях 44, слово при выборе,
«не скажу» тихой кнопкой, дефолта нет. Плюс правка на месте: степень
меняется тапом по огонькам в карточке хозяйки — проставить 30 вещам задним
числом дёшево. «Мечтаю у всего» без дефолта не случается.

**Комната похудела вдвое — мост.** Карточек витрины в зоне нет (ваше чутьё
принято). Но строка-мост «Ещё {n} — в сокровищнице» подвалом зоны — тихая
.45, только хозяйке, только если в витрине есть вещи зоны — отвечает на
послемиграционный шок «куда делась половина». У гостя моста нет: его дверь —
шкатулка в углу.

**Три экрана — ответ один**, различается форма: сетка ярусами; список зоны
строками 52 со знаками 36b; комната списком — секции-зоны без знаков
(чтение и переход). Все три показаны.
