# CHANGES · round51

## Новое

- **Экран «Полки»** (`ZoneList`) — обязательный, единственный вход к полкам без
  места на кадре. 7 живых строк в словаре.
- **Вход в список** — тихая строка «Полки · {count}» под кадром комнаты, цель
  44, одинаково у хозяйки и гостя.
- **Полка `bar`** («Бар и табак») в справочнике зон — только мужской набор.

  Глагол раскрытия не тронут.
- **Инвариант №9** — новый текст целиком (`zones-map-v2.json`).

## Отменено

  некуда. Правило остаётся только для переезда между интерьерами.
- **Статус «скрыта адресно» + 404** — за полкой, выключенной хозяйкой
  (`Room.zonesOff`), и больше ни за чем.
