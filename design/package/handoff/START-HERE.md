# С чего начать — раунд 4

Прочитай этот файл целиком, потом `answers-04.md`. Остальное — по ссылкам оттуда.

## Что случилось в этом раунде

Ваш аудит нашёл 81 непрошедший кадр. Разбирая его, я нашёл причину глубже — **ошибка в
системе координат зон**, а не в кадрах. Из-за неё 26 кадров из 81 переснимать бессмысленно:
прямоугольник показывает не на тот предмет.

**Поэтому порядок работы меняется.** Пересъёмка идёт третьим шагом, а не первым.

## Порядок работы

### Шаг 1. Переразметка — СДЕЛАНО

35 зон переразмечены по вашим кадрам, 3 зоны снять нельзя — предмета в интерьере нет.
Отчёт и таблица «было → стало» — `remap-round4.md`. Сверка глазами — откройте
`remap-check.html` рядом с `rooms.json`.

**Счёт изменился, и не в лучшую сторону:** из 35 переразмеченных зон 10 имели принятый
кадр. Порог им прогоняли против прежнего прямоугольника, то есть против другого участка.
Эти кадры вернулись в пересъёмку.

| | было | стало |
|---|---|---|
| Принято | 49 | **39** |
| К пересъёмке | 81 | **88** |
| Предмета нет в кадре | — | **3** |

### Шаг 2. Осмотр глазами — СДЕЛАНО, все 130 зон

`eyeChecked: true` на каждой. Отчёт — `eyecheck-round5.md`.

Из 92 неосмотренных **14 показывали не тот предмет**, ещё **5 не показывали ничего**.
Исправлено, помечено. Девятнадцать кадров из 88 не ушли впустую.

| | было | стало |
|---|---|---|
| Принято | 39 | **33** |
| К пересъёмке | 88 | **89** |
| Предмета нет в интерьере | 3 | **8** |

**Нужно продуктовое решение по 8 зонам без предмета** — раздел в `eyecheck-round5.md`.
Предлагаю правило: набор зон зависит от интерьера, а не только от пола.

### Шаг 3. Переснять 81 кадр

Только после шагов 1–2. Формула промпта и разбор двух болезней — `reshoot-recipe.md`.

Главное изменение: **материалы и свет не описывать вообще.** Они уже во входной картинке.
Вместо описания — запрет их менять. Так провалились 41 кадр раунда 3: девять строк
описания сцены заставляли модель нарисовать сцену заново.

Порог ваш, проверка ваша. Я снимаю и отдаю ссылки на оригиналы — проверить у себя не могу,
скрипт живёт 30 секунд. Непроверенные кадры молча больше не отдаю.
