# Подсказки — что это, одной строкой

Вы просили описать прежде, чем рисовать. Экрана не нужно.

**«Подсказки» — это одна строка под шапкой комнаты у хозяйки, которая называет
ближайшее незакрытое дело и исчезает, как только дело сделано.**

## Правила

- **Больше одной строки не бывает никогда.** Порядок дел фиксированный, показывается
  первое незакрытое.
- **Скрыть нельзя, и кнопки «понятно» нет** — потому что каждая исчезает сама, когда
  дело закрыто. Строка, от которой нельзя избавиться делом, в этот список не попадает.
- **Это не онбординг и не тур.** Подсказка живёт только пока у неё есть незакрытое дело;
  у новой комнаты их несколько, у обжитой — ни одной, и строки нет вовсе.
- Не появляется у гостя никогда: гость ничего не обставляет.

## Порядок дел (черновой, ждём вашего)

1. в комнате нет ни одной вещи → это состояние занимает пустая комната, подсказки нет;
2. ссылку ещё никому не отправляла;
3. N вещей без цены;
4. N вещей без фотографии;
5. второй способ входа не задан (показывается один раз, перед первым шером — уже есть);
6. ближайший праздник не назван.

Соберём по описанию — строки пришлём в следующем пакете, когда договоримся о порядке.
Если у вас порядок уже есть в сборке, пришлите его: он старше нашего.
