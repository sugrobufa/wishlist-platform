# Что изменилось — round43

Новых значений контракта в пакете два: спецификация верхнего блока настроек
и строки к нему. Прямоугольники, знаки и карточка не тронуты.

## Новые ключи словаря

| Ключ | Строка |
|---|---|
| `Settings.tryOn` | Примерка |
| `Settings.tryOnLine` | «{name}» пока только на этом кадре |
| `Settings.tryOnCancel` | Оставить как есть |
| `Light.overline` | Свет |
| `Light.todMorning` · `todDay` · `todDusk` | Утро · День · Вечер |
| `Light.colorWarm` · `colorWhite` · `colorCandle` | Тёплый · Белый · Свечной |
| `Light.hint` | Свет меняется сразу — он ничего не двигает. Гость увидит комнату в нём же |
| `Light.roomState` | {room} · {tod} · {light} |
| `Light.state*` | утро · день · вечер · тёплый свет · белый свет · свечной свет |

Ключи света заведены отдельной секцией `Light`, а не внутри `Settings`: они
читаются и строкой состояния под кадром, и подписями сегментов.

## Без изменений

`Settings.presetOverline`, `Settings.presetHint`, `Settings.presetApply` — берутся
как есть. `presetHint` в примерке стоит слово в слово: цена переезда не переписана.

## Снято

Строка «Гость видит комнату в свете, который выбрала хозяйка» жила только на доске
и ключа не имела. Её место занял `Light.hint`.
