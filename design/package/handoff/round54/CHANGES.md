# CHANGES · round54

## Добавлено в правила

- **Правило опоры, строка 2:** опора берётся до высоты, на которой предмет
  перестаёт висеть в воздухе, — не до пола.
- **Порядок зон:** сортировка по площади, меньшая последней (выигрывает тап).
  Ручной порядок — признак неверного прямоугольника.
- **Предел приближения** считается от самой узкой зоны текущего дампа, а не
  хранится константой.
- **Дата снимка** обязательна в каждой таблице с числами, не только в шапке
  контракта.
