# Onest — полный шрифт

- `Onest-Variable.ttf` — полный вариативный файл (веса 100–900, латиница +
  кириллица + ext), источник ofl/onest из google/fonts, лицензия SIL OFL.
  Это мастер: из него режутся любые веса и сабсеты.
- `onest-700-*.woff2` — веб-сабсеты веса 700 по unicode-range блокам
  (latin, latin-ext, cyrillic, cyrillic-ext) — подключать как у Google Fonts,
  четырьмя @font-face с unicode-range.

В `grace-lockup.svg` вшит только латинский сабсет 700 (7 KB) — слову «race»
больше не нужно, и файл остаётся лёгким. Полные файлы здесь — для продукта:
интерфейс кириллический, тянуть его с CDN или самохостить — решать вам.
