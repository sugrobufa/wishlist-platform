# Логотип Grace — знак и правила посадки

Знак **и есть заглавная буква**: G-комната с проёмом света открывает слово, рядом набирается
только `race` (Onest 700). Никогда не писать «Grace» текстом рядом со знаком — получится «GGrace».

## Файлы
- `grace-mark.svg` — знак с ореолом. Основная версия, от 20 px и больше.
- `grace-mark-16.svg` — упрощённый: без ореола, контур толще (7). Для 16 px фавикона и любых размеров < 20 px.
- `grace-lockup.svg` — знак + `race`. Onest 700 (латинский сабсет, 7 KB) вшит в файл data-URI внутри @font-face — от машины и установленных шрифтов не зависит. Крайний фолбэк в цепочке — system-ui: слово останется на месте даже там, где SVG-в-<img> режет шрифты (старые Safari). Для таких контекстов запасной путь прежний: знак из `grace-mark.svg` + слово HTML-текстом рядом.

## Построение (сетка 48)
- Кольцо: центр (24,24), r 16.5, контур **6.6**, концы round. Путь: `M35.7 12.3 A16.5 16.5 0 1 0 40.5 24 H32`.
- Проём света: rect 4.2×15, x 21.6, y 16.5, r 2.1, заливка `#FFE9CD`.
- Ореол: эллипс 10×13 в центре, radial `#FFE0B9` .7 → 0. В 16 px версии ореола нет.
- Толщина 6.6 = стем Onest 700 при высоте заглавной. Менять её под другой шрифт нельзя — сначала меняется шрифт слова, потом пересчитывается контур.

## Цвета
- Контур G: `#E7C9A9` (тёплый беж, как весь акцент продукта).
- Свет в проёме: `#FFE9CD` + ореол — единственное тёплое свечение знака.
- Слово `race`: `#F2EDE4`.
- Фон — всегда тёмный `#0B0806` (или фото комнаты под затемнением). На светлом знак не живёт: проём света теряет смысл. Светлой версии не существует.

## Локап (знак + race)
- Высота знака = высоте круглой заглавной Onest 700: при тексте N px знак = **0.75·N** (64 → 48).
- Низ знака сидит на базовой линии слова.
- Зазор знак → `race`: **0.10 высоты знака** (в локапе 5/48).
- `race` всегда строчными, всегда вплотную одним словом, не разрывать и не заменять начертание.

## Охранное поле и минимумы
- Со всех сторон — **0.5 высоты знака** пустоты. Внутрь поля ничего: ни текста, ни иконок, ни счётчиков.
- Локап — от 20 px высоты текста. Ниже 20 px слово выбрасывается, остаётся знак.
- Знак < 20 px — только `grace-mark-16.svg`.

## Где знак живёт
- **Шапка списковых экранов** (друзья, профиль, зал славы): локап слева, текст 20 px, знак 15 px. В комнате шапки нет — поверх комнаты логотип не ставится никогда.
- **Иконка приложения / 44 px**: знак один, по центру, фон `#0B0806`, без слова.
- **Фавикон 16/32**: `grace-mark-16.svg`.
- **Письма** (вход, напоминание, «что подарили»): локап в шапке письма на тёмной плашке; в подвале не повторять.
- **Сплэш**: знак 48 по центру, проём света разгорается 240 ms ease-out — единственная анимация знака. Контур не анимируется, не вращается, не пульсирует.

## Запреты
- Не заливать G, не менять толщину, не наклонять, не ставить на светлое.
- Не отделять свет от буквы: проём без кольца — не знак.
- Не собирать слово из знака и текста «Grace» (двойная G).
- Глифовой G из шрифта в логотипе нет — только нарисованный контур из этого файла.
