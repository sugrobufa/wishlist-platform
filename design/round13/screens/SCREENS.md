# Экраны списков — отрисовки 430×932 @2x

Четыре PNG — телефоны из турнов 29a/29b макета, для сверки с вашей сборкой
из типографики турна 8 и сетки 15a. Живые эталоны — в `Main Screen.dc.html`,
турн 29 (там же разборы).

## 29a — комната списком
- `29a-room-list-owner.png` — хозяйка. Бронь существует ОДНИМ числом в шапке
  («3 забраны»); в группах, строках, ценах — ноль следов. Группы по зонам в
  порядке обхода комнаты, счётчик группы у хозяйки — только число её вещей.
- `29a-room-list-guest.png` — гость. Быстрый фильтр «свободны для подарка» —
  первый чип под переключателем, включён по умолчанию, когда есть занятые;
  скрытое считается плашкой внизу (список не притворяется полным); складчину
  фильтр не прячет — к ней можно присоединиться. Счётчики свободного по зонам,
  «уже дарят» без имени. «Люблю» гостю не показываются — их место в зале славы.

## 29b — зона списком («Украшения»)
- `29b-zone-list-owner-hide.png` — хозяйка, массовое скрытие: долгое нажатие →
  чекбоксы 24 px (цель 44), выбранные строки на .05, панель снизу: тихая
  «Отмена» + «Скрыть 2 вещи» полосой света (низ 2px #E7C9A9 + ореол, без
  заливки). Чипы сортировки: по дате ↓ / по цене / скрытые.
- `29b-zone-list-guest-filter.png` — гость: чип «только свободные» включён,
  счётчик «1 занята · 4 свободны» (гостевой; у хозяйки не существует),
  складчина с прогресс-полосой, скрытое — плашкой.

## Правила строки (общие)
- Пунктир = состояние «хочу»: рамка миниатюры и бейдж. «Люблю» — сплошное,
  без цены. Цена только у «хочу».
- Переключатель «комната ↔ список» — сегмент под шапкой, состояние на сессию.
- Вещь без фото — плитка с рисованной иконкой зоны (сетка 24, контур 1.7).
- Строка занятой вещи приглушается до .5–.55, не исчезает (вне фильтра).
- Тексты не тише .48 над #0B0806; цели нажатия от 44 px.
