# CONTEXT.md — глоссарий домена

Единый язык проекта. Источники: PRD v0.4, дизайн-пакет (`design/package/handoff/`).
Термины ниже — канон; синонимы в коде, тикетах и тестах не используем.

**Правка 09.08.2026 (тикет 124).** Состояний у вещи больше нет — «хочу» и
«люблю» отменены решением владельца. Различие живёт в МЕСТЕ: комната и
сокровищница. Слова `LOVE`, `WANT`, «состояние вещи» из языка проекта
вычеркнуты; встретишь их в коде или тикете — это след, а не термин.

| Термин | Значение | Не путать с |
|---|---|---|
| **Комната (Room)** | Личное пространство человека: фотореальный интерьер-пресет + его вещи. Одна на пользователя, доступна по ссылке `/r/{shareSlug}` | «профиль», «вишлист» |
| **Пресет** | Один из 10 интерьеров (`rooms.json`): cream, warm, emerald, cottage, lux, bold, loft, gamer, sport, study | тема/скин |
| **Зона (Zone)** | Объект интерьера — вход в категорию вещей (полки → книги). Прямоугольник в координатах сцены 430×352. 130 зон на 10 комнат в контракте, 120 в рендере (зона без записи в `zones.json` не показывается — ADR-0003) | «категория» (в UI), «раздел» |
| **Набор зон (zoneSet)** | Предустановка видимых зон: F / M / Все 10. «Пол — предустановка набора зон, а не свойство человека» | пол пользователя |
| **Вещь (Item)** | Единица контента комнаты. Одно тело, ДВА МЕСТА — состояния у вещи нет | «товар», «желание» как отдельная сущность |
| **Комната (место вещи)** | Чего хочется: бронируется, цена по `priceVisibility`, есть степень желания. Технически `inHall = false` | «список желаний» как отдельный экран |
| **Сокровищница (место вещи)** | Что уже моё: не бронируется, цены гостю не видно вовсе. Технически `inHall = true`. Прежнее имя «зал славы» вычеркнуто владельцем 06.08 | «архив», «зал славы» |
| **Степень желания (desire)** | 1–4: «пусть будет · хочется · очень хочется · мечтаю». Пусто («не скажу») — законное значение, шкала не рисуется. ЕДИНСТВЕННЫЙ градиент вещи после отмены состояний | приоритет, оценка |
| **«Дошло»** | Системный переезд комнаты → сокровищница. Совершает хозяйка на экране «что подарили». Побочные эффекты: раскрытие дарителя, предложение связи | покупка |
| **«Вернуть в комнату»** | Ручной переезд обратно: вещь встаёт в свою зону, цена снова видна. МЕСТО ОБРАТИМО — необратимо только раскрытие имени дарителя | отмена подарка |
| **Тихая бронь (Booking)** | Гость занимает вещь КОМНАТЫ. Хозяйка видит только счётчик «N вещей уже забраны» — ни имён, ни вещей. Режимы: тихая / подписанная / складчина | резервирование с уведомлением |
| **Складчина (Pool)** | Несколько гостей скидываются на одну вещь. От пяти участников не прячется | краудфандинг |
| **Праздник (Occasion)** | Повторяющийся день, к которому комната ждёт подарков. Трёх видов, и заводятся они по-разному: **день рождения** — спрашивается один раз в онбординге (единственный, о котором продукт спрашивает); **общая дата** (Новый год, 8 марта, 23 февраля) — приходит плашкой за три недели, её принимают или нет; **свой повод** (годовщина, новоселье) — заводится строкой «Добавить свой повод» и не предлагается никогда. В комнате виден ровно один — ближайший | «событие», разовая дата |
| **«Что подарили»** | Экран-итог праздника: хозяйка отмечает «Дошло», имена раскрываются ровно один раз | лента событий |
| **Сокровищница (Hall)** | Экран-витрина: всё, что уже моё, — и подарки с историей дарения, и свои дорогие вещи. Кто её видит — настройка из трёх положений (ADR-0011), дефолт «всем по ссылке» | «зал славы» (мёртвое имя), архив |
| **Связь (Connection)** | Отношение между людьми: взаимно / слежу / смотрели. Не добавляется вручную — рождается из подарка или открытой ссылки | «друзья» как заявки |
| **Хозяйка / хозяин (owner)** | Владелец комнаты | админ |
| **Гость (guest)** | Смотрит комнату по ссылке без регистрации, тихо бронирует | подписчик |
| **Сцена (Scene)** | Кадр комнаты + слои кадров «открыто» + хотспоты. Наезд камеры считается формулой (`motion.json`), не рисуется | фон |
| **Кадр «открыто»** | Отдельная фотография зоны с раскрытой мебелью (30 шт). Наезд ≠ раскрытие | анимация |
| **Спрятанная вещь (hidden)** | Видит только хозяйка; не удалена | архив вещи |

Правила, которые нельзя менять молча, — PRD §7. Архитектурные решения — `docs/adr/`.
